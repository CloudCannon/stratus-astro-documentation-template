## How this page works

This is the thank-you page for the example form on [Feedback & forms](/feedback-and-forms/#any-other-form). The form's `action` is `/form-success/`, so after CloudCannon Forms records a submission, it sends the visitor here.

It is an ordinary documentation page with no `group`, so it has no sidebar entry. It also sets `noindex: true`, which keeps it out of search. To make your own, copy this file, change the text, and set your form's `action` to the new page's URL.
